# Canva Template Specification: Instagram Carousels
**Prepared for:** Conrad Palmer, Loan Market Gold Coast
**Version:** 2.0 (fonts corrected to Canva Brand Kit)

This document provides a step-by-step specification for creating Instagram carousel templates in Canva, aligned to Conrad Palmer's brand guidelines.

---

## 1. Brand Kit & Canvas Setup

Before creating individual slides, set up the base canvas and ensure all brand assets are ready in Canva.

**Canvas dimensions:** 1080px (width) × 1350px (height) — Instagram Portrait (4:5 ratio). This format occupies maximum screen real estate on mobile.

**Colours:**
- Background: Dark Teal `#1e3239`
- Accent / highlights / icons: LM Blue `#00abe6`
- Primary text: White `#ffffff`

**Typography — use the brand fonts from the Canva Brand Kit:**
- **Geomanist Bold** — all headlines, large display text, data figures, and any text requiring strong visual weight
- **Source Sans Pro** — all body copy, supporting text, sub-headlines, and captions where readability at smaller sizes matters

Do not substitute other fonts. These are the two approved brand typefaces in the Canva Brand Kit.

**Logo:** Use the square LM logo (blue square with white text) from the "Conrad — Brand Assets" Google Drive folder. Minimum 180px wide, up to 220px for visual balance. The logo must appear on every slide and be locked after placement to prevent accidental movement.

## 2. General Design Principles

### Spacing & Margins (The "Safe Zone")
Instagram's interface overlays elements — profile name, share buttons, carousel dots — on top of slides. To prevent content being obscured:

- **Top margin:** 120px (clears the Instagram handle)
- **Bottom margin:** 150px (clears carousel dots and interaction buttons)
- **Side margins:** 80px left and right

All text, graphics, and the logo must remain within the resulting 920px × 1080px central safe zone.

### Hierarchy & Contrast
The viewer's eye should flow from the headline or key data point down to supporting text. Achieve this through stark contrasts in font size and weight. Use LM Blue (`#00abe6`) sparingly — one word in a headline, or one stat. Overusing the accent colour kills its impact.

### Alignment
Left-align text on Hook, Content, and Data slides — easier to read, more professional. Reserve centre alignment for the CTA slide and comparison layouts where symmetry is needed.

## 4. Building the Template in Canva

**Step 1 — Create the design**
Open Canva → **Create a design** → **Custom size** → 1080 × 1350px.

**Step 2 — Set the background**
Click the canvas → click the colour tile in the top menu → add `#1e3239`.

**Step 3 — Set up the Safe Zone guides**
Go to **File → View settings → Show rulers and guides** (or Shift + R).
- Drag horizontal guides to 120px and 1200px (top and bottom margins)
- Drag vertical guides to 80px and 1000px (side margins)

All text, logos, and graphics must stay inside this rectangle.

**Step 4 — Set your brand fonts**
In the text panel, confirm you're using fonts from the Brand Kit:
- Headlines and large display text: **Geomanist Bold**
- Body and supporting copy: **Source Sans Pro**

Press `T` to add text boxes. Always drag them to the full safe zone width (920px) so text wraps correctly when content changes later.

**Step 5 — Add pages and build slide variants**
Use **Add page** to create five blank pages. Build one variant per page using the specifications in Section 3.

**Step 6 — Lock the logo**
Once the Loan Market logo is correctly positioned, select it → click the three dots (`...`) → **Lock**. Do this on every slide to prevent accidental movement.

## 5. Bulk Create (for generating multiple slides quickly)

Canva's Bulk Create feature lets you generate multiple content or data slides from a CSV. Useful once the master template is built.

**Step 1 — Prepare your CSV**
In Excel or Google Sheets, create columns for each variable in the slide design — e.g. `Sub-Headline` and `Body Text`. One row = one slide. Export as CSV.

**Step 2 — Connect data in Canva**
Open the master template. Duplicate the slide you want to bulk-create. In the left sidebar, go to **Apps → Bulk Create → Upload CSV**.

**Step 3 — Link and generate**
Right-click each text box → **Connect data** → choose the matching CSV column. The text box updates to show `{Sub-Headline}` or similar. Once all fields are linked, click **Continue** → select rows → **Generate pages**.

---

## 6. Useful Canva Features

**Circle frame for CTA headshot:** Go to **Elements → Frames → circle**. Drag your headshot onto the frame to snap it to a perfect circle.

**Tidy Up for even spacing:** Select multiple text boxes → **Position → Tidy Up**. Instantly equalises spacing and alignment.

**Copy Style (paint roller):** Select a perfectly formatted text box → click the paint roller icon → click another text box to apply the same font, size, and colour in one click. Use this to maintain consistency across slides without re-entering every setting manually.
