Section 2

General Design Principles

Safe Zone

Instagram overlays the profile handle, share button, and carousel dots on top of the image. Keep all content inside the safe zone.

SAFE
ZONE
920×1080
Top margin: 120px
Bottom margin: 150px
Left margin: 80px
Right margin: 80px

Hierarchy & Contrast

Flow from headline → supporting text via stark size and weight differences. Use LM Blue sparingly — one key word per headline, or one stat. Overuse kills its impact.

Alignment

Left-align on Hook, Content, and Data slides. Centre-align on CTA and Comparison slides where symmetry is needed.

Section 4

Building the Template in Canva

1
Create the design

Open Canva → Create a design → Custom size → 1080 × 1350px

2
Set the background

Click the canvas → colour tile in top menu → add #1e3239

3
Set up the safe zone guides

File → View settings → Show rulers and guides (or Shift + R). Drag horizontal guides to 120px and 1200px. Drag vertical guides to 80px and 1000px.

4
Apply brand fonts from the Brand Kit

Geomanist Bold for headlines. Source Sans Pro for body. Always apply from the Brand Kit panel — do not type font names manually.

5
Add 5 pages, one variant per slide

Use the Add page button. Build each variant using the specs in Section 3. Press T to add text boxes. Drag them to the full safe zone width (920px).

6
Lock the logo on every slide

Select logo → three dots (…) → Lock. Repeat on every slide.

Section 5

Bulk Create (CSV)

Once the master template is built, Bulk Create lets you generate multiple Content or Data slides from a spreadsheet.

1
Prepare your CSV

In Excel or Google Sheets, create columns for each variable — e.g. Sub-Headline and Body Text. One row = one slide. Export as CSV.

2
Connect data in Canva

Open master template → duplicate the target slide → Apps → Bulk Create → Upload CSV.

3
Link fields and generate

Right-click each text box → Connect data → pick the CSV column. Text boxes update to show {Sub-Headline}. Click Continue → select rows → Generate pages.

Section 6

Useful Canva Features

Circle frame for CTA headshot: Elements → Frames → circle. Drag headshot onto frame to snap it into a perfect circle.
Tidy Up for even spacing: Select multiple text boxes → Position → Tidy Up. Instantly equalises spacing and alignment.
Copy Style (paint roller): Select a formatted text box → click the paint roller → click another text box to copy font, size, and colour in one click. Essential for consistency across slides.
